# Calculated Fields



|**Field**|**Formula/Method**|**Purpose**|
|-|-|-|
|Year|Extracted from Order Date|Yearly analysis|
|Month|Extracted from Order Date|Monthly analysis|
|Year-Month|Order Date formatted as yyyy-MMM|Monthly trends|
|Profit Margin|Profit/Sales \* 100|Profitability|
|Average Order Value|Total Sales/Unique Orders|Order-level revenue (calculated in PivotTable)|
