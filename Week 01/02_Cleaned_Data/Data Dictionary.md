### Terminology I have learned as a self-taught beginner Data Analyst



**Dataset**: whole table of data

**Null/missing values**: an empty cell

**Duplicate**: the same row repeated

**Data type**: what kind of value a column holds (text, number, date)

**Standardise**: make formats consistent, such as one spelling per category

**Outlier**: an unusually high or low value

**Data dictionary**: a list that explains each column

**Calculated field**: a new column made from existing ones
